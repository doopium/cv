# 💼 CV & Portfolio Site - Dhairya Jain

This is a personal website repository that showcases different skill domains and portfolios of Dhairya Jain, including data analysis, web development, and design. It includes multiple HTML pages styled with CSS, hosted at **www.doopium.in** using GitHub Pages.

---

## 📌 Features

- 🎨 Visually rich personal branding across three domains:
  - Data Analysis (`dataanalysis.html`)
  - Design (`design.html`)
  - Web Development (`webdev.html`)
- 🌙 Light/Dark theme toggle
- 📊 Linked project showcases with custom styling
- 🌍 Hosted on a custom domain via `CNAME`

---

## 🗂️ Folder & File Structure
CV/
├── .github/workflows/          # GitHub Actions configuration
│   └── blank.yml
├── CNAME                       # Custom domain setup (www.doopium.co)
├── cover.png                   # Header or logo image

├── dataanalysis.html           # Data analysis portfolio page
├── dataanalysis.css            # Styling for data analysis page
├── design.html                 # Design portfolio page
├── design.css                  # Styling for design page
├── webdev.html                 # Web development portfolio page
├── webdev.css                  # Styling for web development page
├── index.html                  # Landing page or Linktree-style overview
├── styles.css                  # Common/shared styles
├── LICENSE                     # Project license file
└── README.md                   # Documentation (this file)
---

## 🚀 Getting Started

1. Clone or download this repo.
2. Open `index.html` to start at the main page.
3. Click on the section links to navigate to:
   - `dataanalysis.html`
   - `design.html`
   - `webdev.html`

---

## 🌐 Hosting with GitHub Pages

- Ensure the repository is set to deploy from the root or `/docs` folder.
- The `CNAME` file sets the domain to:  
  **https://www.doopium.co**

---

## 🛠️ Customization Tips

- **Add Projects** in each HTML under `<div class="project-cards">`
- **Edit Styles** in the corresponding CSS files.
- **Update Domain** by modifying the `CNAME` file.
